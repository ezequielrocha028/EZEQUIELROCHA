# Como adicionar as imagens do site

Todas as imagens do site ficam **dentro desta pasta `imagens/`**. Basta arrastar
o arquivo para cá pelo GitHub (botão "Add file" → "Upload files" nesta pasta)
usando **exatamente o nome abaixo** (tudo minúsculo, sem espaço e sem acento —
isso evita links quebrados).

## ⬜ Faltam enviar

| Nome do arquivo (use exatamente este) | Onde aparece no site | Tamanho sugerido |
|---|---|---|
| `textura-bege.jpg` | Textura de fundo bege (página e caixa "A nossa troca") | qualquer, paisagem, leve |
| `textura-verde-escuro.jpg` | Fundo da seção "Missão FarLands" | qualquer, paisagem, leve |
| `textura-verde-claro.jpg` | Fundo da seção "Convite à Parceria" | qualquer, paisagem, leve |
| `foto-capa.jpg` | Foto grande do topo (capa/hero) | horizontal, boa resolução (ex: 1600×1000) |
| `grafismo-escuro.png` | Grafismo decorativo (seção "Quem sou eu") | PNG com fundo transparente |
| `grafismo-claro.png` | Grafismo decorativo (seção "Missão FarLands") | PNG com fundo transparente |
| `foto-parceria.jpg` | Sua foto na seção "Convite à Parceria" | vertical ou paisagem |

## Regra de ouro
Sempre que enviar um arquivo, salve-o **exatamente com o nome da tabela acima**
(mesma extensão: `.jpg` ou `.png`). Não é preciso mexer no HTML — o código já
está apontando para esses nomes dentro de `imagens/`.
